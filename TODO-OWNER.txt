CACADUU PPI – WHAT THE OWNER DOES BY HAND
==========================================

How this list works
- Each item has a number that never changes. New items get the next number.
- When you finish items, write to Claude for example "done 2, 4". Claude moves them to DONE with the date.
- Claude never sees secret values: when an item says "add the secret X", you paste the value yourself.
- Things done before 31 October 2026 are not listed here (SETUP.md keeps that history).

1. Choose an SMS provider in the EU that can RECEIVE SMS (for "Hodiny cez SMS"; not Twilio)
   Why: owners will text their opening hours to this number. Everything else of "Hodiny cez SMS" already works.
   Steps:
   a) Pick a provider that gives a phone number which receives SMS and forwards each SMS to a web address (a
      "webhook" or "inbound SMS URL").
   b) Write its name to Claude. Claude then adds it and tells you which secrets to add and where.

2. Connect the Google Business Profile (after Google approves the API access)
   Why: opening hours changed in Cacaduu (or by SMS) also change on Google Maps.
   Steps:
   a) Wait for Google's e-mail that the Business Profile API access request is approved.
   b) cacaduu.com → log in → Môj obchod → Hodiny cez SMS → "Pripojiť Google" → log in with the Google account that
      manages the shop's profile → allow → choose the shop's location.
   c) Click "Poslať hodiny do Google teraz" and check the hours on Google Maps.

   d) In a new Claude chat ask: "Aké mám otváracie hodiny?" and "Aké mám dnes rezervácie?".
   e) Tell Claude what happened (a screenshot is enough if something fails).
